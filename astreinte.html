🌙 Registre — qui est d'astreinte cette semaine
Chargement du registre…
Saisissez le nom de l'agent qui couvre l'astreinte pour chaque jour, pour chaque campagne suivie. Une cellule en rouge signale un jour sans personne d'affecté. La saisie propose tous les agents qualifiés sur la compétence de la campagne (pas seulement ceux actifs aujourd'hui) — à défaut de compétences chargées, l'ensemble des agents connus est proposé. Le badge ⇄ agent mutualisé signale un agent également qualifié sur d'autres campagnes — utile pour repérer une éventuelle surcharge avant de confirmer l'affectation. Le registre est partagé entre tous les superviseurs et enregistré automatiquement.
