À quoi ça sert

Contrôler les heures réelles (téléphonie INO entrante + Evo sortant) de 100 % des agents, jour par jour, et les comparer à la saisie paie importée (Total H prod). L'objectif est de repérer les incohérences (agent payé sans activité, écart anormal), pas de mesurer la paie à la minute.

Boutons d'en-tête

Registre / Synthèse / Grille3 vues des mêmes données : détail agent×jour · totaux par agent · calendrier couleur.
Aujourd'hui · 7j · 14j · 30j · Mois-1Raccourcis de période (max 31 jours — protection du quota INO).
Du … au … · ChargerPériode libre puis chargement. Les jours passés sont déjà sauvegardés : ils ne re-téléchargent pas INO. Seul aujourd'hui est live (rafraîchi au max toutes les 10 min).
Import paieCharger l'export du logiciel de paye (.xlsx ou .csv). Colonnes reconnues : Nom Prénom, Date, Total Prod, Durée plage, Absence, Motif.
Export CSVTélécharge la vue courante (s'ouvre dans Excel), avec les colonnes sources séparées.
Quota INOConsommation live de l'API (limite 1000/h). Au-delà de 70 % les appels sont suspendus ; l'heure de remise à zéro est affichée. Le cache continue de servir.

Colonnes du registre

ConnexionHeure de mise en production : session Evo réelle E, sinon login INO du jour L, sinon 1ᵉʳ appel I (approché).
DéconnexionFin de session Evo E ou dernier appel INO I. « — » = encore connecté.

Comm.Temps de communication cumulé (talk).
Appels INO · CU EvoEntrants/sortants INO · Contacts argumentés Evo (mesurable).
ÉcartH prod paie − présence. −1h ≈ normal (déjeuner). Rouge = payé > présent ou saisie sans activité.
Fiab.✓ fiable (2 sources concordent) · ok · ⚠ vérifier (anomalie) · ? INO (données incomplètes).
Sources : INO (appels — connexion/1ᵉʳ appel, dernier appel, communication, nb d'appels) · Evo (sessions réelles = connexion/déconnexion exactes) · Paie (Total H prod importé). ⚠️ Pour les agents INO, faute d'historique de session côté INO, la présence est approchée par l'amplitude 1ᵉʳ→dernier appel (inclut pauses/déjeuner) — l'écart attendu est donc négatif d'environ 1h sur une journée normale. La connexion INO utilise le login réel quand il est disponible L. Evo = sessions exactes. L'écart est un détecteur d'incohérence.
